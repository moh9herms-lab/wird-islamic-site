# وِرد | مشروع موقع إسلامي عربي

موقع عربي بتصميم متجاوب (RTL) يحتوي على: مواقيت الصلاة والأذان بصوت مؤذن تختاره، صفحات القرآن، التفسير الميسر عند الضغط على الآية، فهرس السور المكية والمدنية، مكتبة أذكار متعددة الأبواب مع العدادات، سبحة إلكترونية تحفظ التقدم، ومساعد بحث شرعي مرتبط بالمواقع المحددة.

## التشغيل

**المتطلبات:** Node.js 20 أو أحدث، ومتصفح حديث، واتصال إنترنت لجلب مواقيت الصلاة والقرآن ومحتوى الأذكار والمقاطع الصوتية.

```bash
cd wird_website
node server.mjs
```

ثم افتح http://localhost:3000 . يمكن فتح `index.html` مباشرة لمشاهدة بعض أجزاء الواجهة، لكن التشغيل عبر الخادم أكثر موثوقية، وميزة المساعد الآلي تحتاجه.

## تفعيل المساعد الشرعي

هذا الجزء **حقيقي وليس محاكاة**، لكنه لا يعمل من دون مفتاح API خاص بمالك الموقع. لتفعيله:

1. أنشئ مفتاح OpenAI API في حسابك المُصرّح له؛ قد يترتب على استخدام البحث والنموذج رسوم.
2. أنشئ ملف `.env` في مجلد المشروع بحسب `.env.example`، وضع `OPENAI_API_KEY=...`، ولا ترفعه إلى مستودع عام.
3. شغّل `node --env-file=.env server.mjs`. يدعم تغيير النموذج عبر `OPENAI_MODEL` إلى نموذج متاح لحسابك يدعم `web_search`.
4. البحث على الخادم يستخدم `Responses API` بأداة `web_search` مع تقييد النطاقات إلى `binbaz.org.sa`, `islamweb.net`, `islamqa.info`, `dorar.net`، ويعرض الروابط الفعلية التي استُخدمت. إذا لم يحصل على مصادر، لا يختلق الإجابات.

المساعد ليس بديلًا عن المفتي. يدعم الخادم حدًا بسيطًا 12 طلبًا في الساعة لكل عنوان IP. عند الإطلاق العام ينبغي إضافة نظام حماية من إساءة الاستخدام، ومراقبة التكلفة، وسياسة خصوصية، والتحقق من جودة الإجابات الشرعية.

## ما يعمل من دون إعدادات مدفوعة

- واجهة كاملة متجاوبة مع الكمبيوتر والجوال، وتحتفظ بالتفضيلات محليًا عبر `localStorage`.
- مواقيت الصلوات الخمس حسب المدينة أو الموقع الجغرافي اختياريًا، مع طريقة حساب محددة؛ الساعة والعدّ التنازلي بناء على بيانات حقيقية، وليست أوقاتًا وهمية.
- اختيار 3 أصوات أذان (مشاري العفاسي، أحمد النفيس، منصور الزهراني)، وتجربة تشغيلها؛ التشغيل التلقائي يتطلب تفاعل المستخدم والسماح بالصوت وبقاء الصفحة مفتوحة.
- القرآن بترتيب صفحات مصحف المدينة (604 صفحة) أو حسب السورة وبالرسم العثماني أو الإملائي؛ قائمة 114 سورة والتمييز بين المكي والمدني **تصنيف نزول للسور لا نوع مصحف منفصل**.
- تفسير الميسر من مجمع الملك فهد، يجلب نصّه عبر إصدار `ar.muyassar` من خدمة AlQuran Cloud عند فتح آية؛ قراء 3 لتلاوة الآية الأولى المعروضة.
- 14 بابًا من الأذكار اليومية، مع عرض البيانات الموسعة عند توفر مصدرها، وعدادات تكرار لكل ذكر. تظهر مجموعة مختصرة بديلة عند انقطاع الإنترنت.
- سبحة متعددة الأذكار بأهداف 33 و100 وحر، مع حفظ التقدم والإجمالي محليًا.

## حدود التشغيل

- **لا يمكن ضمان الأذان عند إغلاق تبويب المتصفح أو إيقاف الجهاز**. يتطلب ذلك تطبيقًا أو نظام تنبيهات خلفية واشتراك Push/خادمًا مناسبًا. حتى مع فتح الصفحة قد تمنع سياسة التشغيل التلقائي الصوت حتى يضغط المستخدم تجربة الصوت.
- **مواقيت الصلاة حسابية** وقد تختلف عن التقويم الرسمي والمساجد في منطقتك، ويجب مقارنتها بمصدر منطقتك قبل الاعتماد عليها للعبادة.
- بيانات القرآن والتفسير والأذكار تعتمد على خدمات خارجية؛ عند انقطاعها لا تُعرض آيات مزيفة. الأذكار البديلة مختصرة ولا تمثل كل أذكار السنة. راجع الألفاظ والتخريج والمصادر والترخيص بعناية قبل الإطلاق العام.
- صفحات المصحف هي **ترتيب صفحات مصحف المدينة مع عرض نصّي**، وليست صورًا مطابقة للطباعة أو خطوطًا خاصة بكل صفحة. الرسم الإملائي لتسهيل القراءة، وليس رواية مختلفة.
- لم يُضف دعم روايات منفصلة مثل ورش أو قالون، لأن ذلك يحتاج بيانات رسم وقراءات موثقة خاصة بكل رواية، وليس مجرد تغيير تنسيق الخط.

## المصادر والاعتمادات

- **مواقيت الصلاة:** [AlAdhan Prayer Times API](https://aladhan.com/prayer-times-api)؛ طريقة أم القرى `method=4` وغيرها. حقوق والتزامات الاستخدام بحسب مزود الخدمة.
- **الأذان الصوتي:** روابط الملفات المستضافة على [AlAdhan — Download Adhans](https://aladhan.com/download-adhans). لا نعيد توزيع الملفات الصوتية؛ يجب التحقق من شروط استخدام التسجيلات قبل النشر التجاري.
- **القرآن والنصوص الصوتية:** [AlQuran Cloud API](https://alquran.cloud/api)؛ إصدارات `quran-uthmani`, `quran-simple`, `ar.alafasy`, `ar.abdurrahmaansudais`, `ar.husary`، مع التأكد من توافر الإصدارات عند التشغيل.
- **التفسير الميسر:** [مجمع الملك فهد لطباعة المصحف الشريف — منصة مطوري القرآن](https://qurancomplex.gov.sa/quran-dev/)؛ النص مقدم آية بآية عبر `ar.muyassar` من AlQuran Cloud. يخضع لاشتراطات المصدر الأصلي، ويُنصح بإدراج النسخة الرسمية مباشرة عند إصدار المنتج النهائي.
- **الأذكار الموسعة:** [islamic-library-data](https://github.com/mohammed-2-5/islamic-library-data) وتُطلب عبر jsDelivr؛ 14 مجموعة من مجموعات الأذكار العامة، ويتطلب استخدامها مراجعة المصدر والتوثيق والترخيص بشكل مستقل. الأذكار المختصرة المضمنة في المشروع تعرض نصوصًا من القرآن والحديث العام.
- **الذكاء الاصطناعي:** [OpenAI Responses API مع web_search](https://developers.openai.com/api/docs/guides/tools-web-search)؛ تقييد البحث عبر allowed_domains.

## النشر

يمكن نشر المشروع على خادم Node.js يدعم متغيرات البيئة مثل Railway أو Render أو VPS، مع تفعيل HTTPS، وعدم إظهار المفتاح في ملفات الواجهة. إن استخدمت استضافة صفحات ثابتة فقط، تعمل الأدوات العامة لكن لن يعمل مسار `/api/ask` من دون خدمة خلفية.

**تنبيه:** النسخة تجربة تطبيق قابلة للتشغيل واختبار الواجهات، وليست منتجًا دينيًا راجعه مختصون قبل نشره للعامة. يجب اختبار APIs وسياسات الصوت والتراخيص والتواريخ الهجرية والإشعارات على خدمة الاستضافة الفعلية.
